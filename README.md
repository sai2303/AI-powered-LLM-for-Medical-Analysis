🧠 AI-Powered Medical Image Analysis
FastAPI + Groq Llama Vision (LLM) + Python

This project is an AI-powered medical analysis system that allows users to upload medical images (X-rays, scans, MRI images, etc.) and get intelligent, LLM-generated insights. It uses Groq’s Llama Vision model to analyze images and answer medical queries with contextual reasoning.
The backend is built with FastAPI, supporting image validation, multimodal prompts, and real-time inference.

🚀 Features

🖼 Upload medical images (X-ray, scan, etc.)

🔍 LLM-powered medical reasoning using Groq’s Llama Vision model

🤖 Answers user medical questions based on the uploaded image

⚡ FastAPI backend with async request handling

🛡 Input validation & error handling

📦 Base64 encoding + multimodal prompt support

📊 JSON API output for easy integration

🏗️ Tech Stack

Python

FastAPI

Groq Llama Vision model (LLM)

Pillow (PIL) for image processing

Base64 for image encoding

Requests for Groq API calls

HTML + JS (for frontend interface)
